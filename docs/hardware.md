# PCB1 硬件与固件对应

硬件证据保存在 `hardware/pcb1.json`，从 PCB1、P1 及 E73 原厂资料核对。不会沿用另一款 GridRoll PCB 的 GPIO。

| 功能 | 左侧 | 右侧 |
| --- | --- | --- |
| ROW0–ROW3 | P0.29 / P0.31 / P0.10 / P0.09 | P0.09 / P0.05 / P0.29 / P0.31 |
| 本地 COL0–COL5 | P1.11 / P1.10 / P0.03 / P0.28 / P1.13 / P0.30 | P0.24 / P0.10 / P0.03 / P1.11 / P1.10 / P0.28 |
| 电池 ADC | P0.04 / AIN2 | P0.04 / AIN2 |
| EC11 A / B | P0.13 / P0.24 | 无 |
| PAW3222 SDIO / SCLK | 无 | P1.09 / P0.12 |
| PAW3222 NCS / MOTION | 无 | P0.13 / P0.15，低电平有效 |
| 复位 | P0.18 | P0.18 |

矩阵扫描方向 `col2row`：列输出高电平，行输入带下拉。左右各 4×6，右侧全局列偏移 6；全局位置为 47 个。左侧 `RC(3,3)` 是旋钮按压 SW47；右侧 `RC(3,8)` 留给轨迹球，无按键。Studio 物理坐标来自 PCB 实际开关位置，包含中缝。

P0.09/P0.10 的 NFC 功能通过 UICR 关闭，用作矩阵 GPIO；P0.18 配置为硬件复位。E73 自带高频晶体，低频使用内部 RC，应用和引导程序均不依赖外接 32.768 kHz 晶体。

PCB1 外部 XC6206 提供 3.3 V，同时连接模块 VDD/VDDH；采用普通电压模式，不启用需要外部电感的 DC/DC。两侧电池为用户确认的 200–250 mAh、带保护板。

电池上臂 820 kΩ、下臂 2 MΩ，采样倍率为 `(820k + 2M) / 2M = 1.41`。使用官方 `zmk,battery-voltage-divider` 驱动，ADC 通道 2、40 µs 采样时间。该高阻分压与小电池的实际读数、续航需实测。

左侧旋钮型号 EC11E15244B2，每圈 15 脉冲、30 卡点；固件 `steps=60`、`triggers-per-rotation=30`。如果接线或安装方向使音量反向，在键位配置中交换旋转的两个绑定。

轨迹球小板为「3222传感器模块」，没有独立 MCU；驱动运行在右侧 E73。实际器件为用户确认的 PAW3222LU-TJDU，原理图 PAW3220LU 是旧标注。保留参考仓库的三线半双工 GPIO 协议；读数据前释放 SDIO，结束或失败后恢复 NCS、SCLK、SDIO。MOTION 中断触发工作队列，运动期间每 5 ms 读取，传感器自动休眠保持开启。初始化失败不会禁用键盘。

`config/trackball.dtsi` 提供方向、轴交换、CPI 和滚动比例配置。默认 CPI 988（38 的倍数），指针比例 1:1，滚动比例 1:12。方向位：交换 XY 为 1，反转 X 为 2，反转 Y 为 4，可按位合并；方向最终由上板测试确定。

| Flash 区域 | 地址 |
| --- | --- |
| MBR / S140 6.1.1 | `0x00000–0x25FFF` |
| ZMK 应用 | `0x26000–0xEBFFF` |
| ZMK 设置 | `0xEC000–0xF3FFF` |
| UF2 引导程序及其保留页 | `0xF4000–0xFFFFF` |

首次烧录包还写入 UICR 的引导地址、复位、NFC 及 REGOUT0。CI 校验应用和引导程序不覆盖 ZMK 设置区；合并发生重叠即拒绝打包。
