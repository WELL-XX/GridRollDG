# 使用、Studio 与故障排查

## 左右连接及电脑连接

右侧是主机，左侧通过蓝牙连接右侧。两侧正常固件上电后，分体连接自动建立；不需要把左侧单独与电脑配对。

右侧默认优先 USB；没有 USB 数据连接时使用蓝牙。用蓝牙连接电脑时，在电脑中添加 `GridRollDG`。切换输出和蓝牙配置的方法如下。

## 默认层操作

按住底行的 Fn 可输入数字、功能键及导航键。按住右侧底行 Mouse 时，轨迹球变为双轴滚动，右侧 H/J/K/L/分号分别是鼠标左键、中键、右键、后退、前进；左侧旋钮输出滚轮。

同时按住 Fn + Mouse 进入系统层。以下名称对应基础层印象中的位置：

| 组合 | 功能 |
| --- | --- |
| Fn + Mouse + Esc | Studio 解锁 |
| Fn + Mouse + Q | 选择 USB 输出 |
| Fn + Mouse + W | 选择蓝牙输出 |
| Fn + Mouse + Tab / A / S / D / F | 选择蓝牙配置 0 / 1 / 2 / 3 / 4 |
| Fn + Mouse + G | 清除当前电脑蓝牙配对 |
| Fn + Mouse + 左 Shift | 左侧进入引导程序 |
| Fn + Mouse + 右 Shift | 右侧进入引导程序 |

左右进入引导程序的按键由产生该按键的一侧执行。左侧连接失效时，直接双击左侧复位按钮即可。

## ZMK Studio

1. 将右侧 USB 连接电脑，打开官方 [ZMK Studio](https://studio.zmk.dev/)。使用支持 Web Serial 的浏览器，选择 GridRollDG 的串口。
2. 按 Fn + Mouse + Esc 解锁，连接后会显示 PCB1 的 47 个按键位置。轨迹球位置没有虚构按键。
3. 修改所需按键和层，执行保存。断电重启后核对保存的键位。

Studio 用于修改按键；传感器 CPI、轴方向、滚动倍率、矩阵及旋钮硬件参数通过仓库配置修改并重编译。调整底行层切换键或系统层时，请保留可用的解锁入口。

## 故障排查

| 现象 | 检查顺序 |
| --- | --- |
| 左侧完全不响应 | 左侧供电 → 确认刷的是 left 固件 → 两侧重启 → 必要时两侧 settings-reset 后重新刷回 |
| 一行或一列按键失效 | 对照 `docs/hardware.md` GPIO 及焊点；检查矩阵二极管方向和短路 |
| 旋钮每卡点触发多次或漏触发 | 核对型号、A/B/公共端、焊点；当前参数针对 15 脉冲、30 卡点 EC11 |
| 轨迹球无响应，键盘正常 | 检查小板供电及 FPC 的 SDIO/NCS/MOTION/SCLK/GND/VCC；右侧诊断固件的 RTT 日志会报告初始化结果 |
| 光标方向不对 | 修改 `config/trackball.dtsi` 的方向位后重编译；同一方向配置也作用于轨迹球滚动 |
| 蓝牙已连接但无输入 | 核对当前配置槽位及输出选择；删除电脑旧配对，再清除对应槽位并重新配对 |
| Studio 无法连接 | 右侧 USB 数据线 → 支持 Web Serial 的浏览器 → 关闭占用串口的软件 → 系统层解锁 |
| Studio 保存后行为异常 | 清除两侧设置并重刷对应固件以恢复仓库默认键位 |
| 电池百分比明显异常 | 用万用表测电池电压及 ADC 分压点；确认上臂 820kΩ、下臂 2MΩ，校准前记录实测值 |
| 续航不足 | 记录两侧电流、轨迹球运动/静止及 USB 状态；首版保留传感器休眠，整机深睡关闭，依据实测再优化 |

诊断固件的日志比正常固件多，续航评估使用正常版本。
